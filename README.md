# SimpleSuicide

## Requirements

- Minecraft Java Edition 26.3
- Java 25 or newer
- Fabric Loader 0.19.5 or newer
- Fabric API 0.161.0+26.3 or newer for Minecraft 26.3

## Build

Run `./gradlew build` (Windows: `.\gradlew.bat build`) with JDK 25. The mod JAR is generated in `build/libs/`.

## Usage

- Add a command `/suicide` for all players to quickly kill himself without cheating.
